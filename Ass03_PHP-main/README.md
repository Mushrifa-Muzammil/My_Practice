## 📖 About The Project

This is a **professional Invoice Generation System** for ABC Shop that demonstrates advanced web development concepts:

- **Dynamic item management** – Add/remove items dynamically with JavaScript
- **Tiered discount calculation** – Quantity-based discounts and free item promotions
- **Professional invoice layout** – Print-ready invoice display
- **Comprehensive validation** – Client-side (JS) + server-side (PHP) validation
- **Responsive design** – Works on desktop, tablet, and mobile

This project simulates a real-world retail billing system with professional UI/UX.

## ✨ Features

| Category | Features |
|----------|----------|
| **Shop Details** | Name, Address, Contact, Email with validation |
| **Dynamic Items** | Add/remove items dynamically (starts with 3, unlimited addition) |
| **Discount Logic** | 2% (11-20), 10% (21-50), free items (>50: 5 free per 30) |
| **Invoice Display** | Professional layout with itemized breakdown |
| **Print Functionality** | One-click print invoice |
| **Client Validation** | Real-time validation with visual feedback |
| **Server Validation** | Contact format, email format, XSS protection |
| **UI/UX** | Gradient design, hover effects, animations, icons |

## 🛠️ Built With

- **HTML5** – Semantic structure
- **CSS3** – Advanced styling, gradients, animations, responsive design
- **JavaScript (ES6)** – Dynamic item management, form validation, DOM manipulation
- **PHP 7+** – Server-side processing, discount calculations, invoice generation
- **Font Awesome 6** – Professional icons throughout
