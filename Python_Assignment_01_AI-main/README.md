## 📖 About The Project

This assignment contains **3 foundational Python programs** that demonstrate:

- **Basic output** using `print()`
- **Variable declaration** and arithmetic operations
- **User input** handling with `input()`
- **Conditional statements** (`if`, `elif`, `else`)
- **Type conversion** (string to float)

The highlight of this assignment is a **BMI (Body Mass Index) Calculator** that takes user input and classifies it into health categories. This is an ideal starting point for beginners learning Python programming.

## 📝 Programs Included

| # | Program Name | Description | Key Concepts |
|---|--------------|-------------|--------------|
| 1 | **Welcome Message** | Prints a simple welcome message | `print()` function |
| 2 | **Add Two Numbers** | Declares two variables, adds them, and displays result | Variables, arithmetic (`+`), `print()` |
| 3 | **BMI Calculator** | Takes BMI input and classifies into health categories | `input()`, `float()`, `if-elif-else` |
