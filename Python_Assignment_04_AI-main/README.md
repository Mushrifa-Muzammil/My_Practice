## 📖 About The Project

This assignment contains **6 Python programs** that demonstrate the use of **conditional statements** (`if`, `elif`, `else`). It covers fundamental decision-making concepts in programming, including:

- Basic `if` statements
- `if-else` for two-way decisions
- `if-elif-else` for multi-way decisions
- Input validation and user interaction
- Comparison operators and logical conditions

This is an ideal learning resource for beginners understanding how to control program flow based on conditions.

## 📚 Topics Covered

| Topic | Description |
|-------|-------------|
| `if` statement | Execute code block when condition is true |
| `if-else` statement | Execute one block if true, another if false |
| `if-elif-else` statement | Multiple conditional branches |
| Comparison Operators | `==`, `<`, `>`, `<=`, `>=`, `!=` |
| Modulo Operator (`%`) | Check divisibility |
| Type Conversion | `int()` for user input |
| String Comparison | Password validation |

## 📝 Programs Included

| # | Program Name | Description | Concepts Used |
|---|--------------|-------------|---------------|
| 1 | **Simple Value Check** | Checks if a value equals 10 | `if` statement, print |
| 2 | **User Input Value Check** | Takes user input and checks if it equals 10 | `input()`, `int()`, `if` |
| 3 | **Password Validator** | Compares entered password with correct password | String comparison, `if-else` |
| 4 | **Age Category Classifier** | Classifies age into Child, Teen, Adult, Senior | `if-elif-else`, comparison operators |
| 5 | **Positive/Negative Number** | Determines if number is positive, negative, or zero | `if-elif-else`, comparison |
| 6 | **Divisibility Check** | Checks if number is divisible by 5 | Modulo operator (`%`), `if-else` |
