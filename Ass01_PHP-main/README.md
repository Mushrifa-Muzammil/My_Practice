## 📖 About The Project

This is a **complete Job Application Form system** with robust validation on **both client and server sides**. It demonstrates a professional recruitment workflow including:

- **Front-end:** Modern, responsive form with real-time validation
- **Back-end:** PHP processing with file upload, data sanitization, and validation
- **Security:** Input sanitization, file type/size restrictions, XSS prevention

Perfect for learning how to build secure, production-ready web forms.

## ✨ Features

| Category | Features |
|----------|----------|
| **Form Fields** | Name, Email, Contact, DOB, Position, Resume, Cover Letter, LinkedIn, Experience, Skills |
| **Client-side Validation** | Real-time validation with visual feedback (green/red borders), error summaries, smooth scrolling |
| **Server-side Validation** | Required fields, email format, phone format, age (18+), file type (PDF/DOC), file size (max 2MB) |
| **Security** | XSS prevention with `htmlspecialchars()`, input sanitization, file upload restrictions |
| **User Experience** | Sticky form values, animated error messages, success/error pages, responsive design |
| **File Upload** | Automatic `uploads/` directory creation, secure file handling |

## 🛠️ Built With

- **HTML5** – Semantic form structure
- **CSS3** – Modern gradient styling, animations, responsive design
- **JavaScript (ES6)** – Real-time client-side validation
- **PHP 7+** – Server-side validation, file upload, data processing
