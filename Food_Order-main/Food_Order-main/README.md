## 📖 About The Project

This is a **complete Online Food Delivery Website** that provides a full user experience for ordering food online. It includes:

- **Food browsing** by categories and menu items
- **Shopping cart** functionality with item management
- **User authentication** (login system)
- **Contact form** with PHP processing
- **Order placement** with delivery details
- **Responsive design** that works on all devices

The project demonstrates a real-world e-commerce food delivery platform with both front-end and back-end components.

## ✨ Features

| Category | Features |
|----------|----------|
| **Food Browsing** | Categories (Pizza, Sandwich, Burger), Food menu with images and prices |
| **Shopping Cart** | Add/remove items, quantity selection, real-time total calculation |
| **User Account** | Login page (PHP backend ready), session management |
| **Contact System** | Contact form with PHP processing, Google Maps integration |
| **Order System** | Order confirmation form, delivery details collection |
| **Search** | Food search functionality |
| **UI/UX** | Hover effects (Hover.css), sticky navigation, back-to-top button, responsive grid layout |
| **Backend Ready** | PHP form handlers for contact and login |

## 📄 Pages Overview

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Main landing page with categories and food menu |
| Categories | `categories.html` | Browse food by category with image overlays |
| Category Foods | `category-foods.html` | Foods within a specific category |
| Foods | `foods.html` | Complete food menu with search |
| Food Search | `food-search.html` | Search results page |
| Order | `order.html` | Order confirmation and delivery details form |
| Contact | `contact.html` | Contact form with Google Maps location |
| Login | `login.html` | User login page |
| Process | `process.php` | PHP handler for contact and login forms |

## 🛠️ Built With

- **HTML5** – Semantic structure
- **CSS3** – Custom styling, CSS Grid, Flexbox, animations
- **JavaScript (ES6)** – Shopping cart, form validation, dynamic UI
- **PHP 7+** – Form processing (contact, login)
- **jQuery** – DOM manipulation and UI interactions
- **Hover.css** – Smooth hover animations
- **Font Awesome** – Icons throughout the site
- **Google Maps Embed** – Location display
