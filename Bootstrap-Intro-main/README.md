## 📖 About The Project

This is a **simple introductory project** created to practice and demonstrate **Bootstrap 5** fundamentals. It showcases basic Bootstrap components including:

- **Cards** – Display content in a flexible and extensible container
- **Responsive layout** – Mobile-first design approach
- **Bootstrap styling** – Using pre-built CSS classes

This project serves as a learning sandbox for understanding how Bootstrap components work and how to implement them quickly.

## ✨ Features

| Category | Features |
|----------|----------|
| **Bootstrap Components** | Cards, typography, buttons, grid system |
| **Responsive Design** | Mobile-first layout that adapts to screen size |
| **Modern Styling** | Bootstrap's default clean and professional look |
