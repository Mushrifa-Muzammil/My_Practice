## 📖 About The Project

This project is a fully functional **Job Application Form** that demonstrates a complete client-server web application workflow. It features a responsive, user-friendly interface for collecting candidate information, including personal details, position applied for, resume upload, skills, and work experience. The backend (PHP) processes the submitted data and displays a confirmation summary.

It serves as an excellent example of:
- Front-end form design with validation.
- Back-end data handling with PHP.
- File upload capability.

## ✨ Features

- **📝 Comprehensive Form** – Collects all necessary candidate data (name, contact, DOB, position, experience, etc.).
- **📎 Resume Upload** – Allows uploading PDF, DOC, or DOCX files.
- **✅ Skill Selection** – Checkbox group for selecting multiple skills.
- **💾 PHP Backend Processing** – Receives form data and displays a submission summary.
- **🎨 Modern, Responsive UI** – Clean, gradient-background design using Google Fonts and CSS3.
- **🔒 Basic Input Validation** – Uses HTML5 required attributes and input types (email, tel, url, number).
- **✨ Interactive Elements** – Input fields with focus effects and a styled submit button.

## 🛠️ Built With

- **HTML5** – Form structure
- **CSS3** – Styling, layout, and responsive design (Google Fonts, gradients)
- **PHP 7+** – Server-side data processing
- **GitHub Pages** – Front-end hosting
