## 📖 About The Project

This is a **simple yet functional Grocery Bill Calculator** that demonstrates fundamental PHP concepts:

- Collecting user input via HTML forms
- Processing form data with PHP
- Performing arithmetic calculations
- Displaying dynamic results

It's an excellent beginner project for understanding how PHP works with HTML forms to create interactive web applications.

## ✨ Features

| Category | Features |
|----------|----------|
| **Input Fields** | 6 grocery items with quantity selection |
| **Calculation** | Automatic total calculation based on quantities |
| **Validation** | Minimum value 0 (no negative quantities) |
| **User Experience** | Simple, clean interface with easy navigation |
| **Responsive** | Centered form layout that works on all devices |

## 🛠️ Built With

- **HTML5** – Simple form structure
- **CSS3** – Clean, centered layout styling
- **PHP 7+** – Form processing and bill calculation
