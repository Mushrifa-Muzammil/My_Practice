## 📌 Overview

This is a **practice/demo portfolio website** created for learning purposes. It's an experimental project to test modern web design concepts, animations, and responsive layouts.

> ⚠️ **NOTE**: This is NOT my professional portfolio. This is just a practice/demo version to experiment with different design patterns and features.

## 🎨 Features Demonstrated

- CSS Grid & Flexbox layouts
- Gradient backgrounds and text effects
- CSS animations (float, rotate, hover effects)
- Responsive design with media queries
- Mobile hamburger menu
- Smooth scrolling navigation
- CSS variables for theming
- Form handling with JavaScript
- Glass morphism effects (backdrop-filter)

## 🛠️ Technologies Used (Practice)

- HTML5 (Semantic elements)
- CSS3 (Custom properties, animations, flexbox, grid)
- Vanilla JavaScript (DOM manipulation, event handling)
- Font Awesome 6 (Icons)
- No frameworks - pure practice code
