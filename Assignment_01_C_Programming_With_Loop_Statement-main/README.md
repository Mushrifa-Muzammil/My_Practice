## 📖 About The Project

This repository contains a comprehensive collection of **C programming pattern programs** using **loop statements**. It's designed to help learners master nested loops, pattern generation, and algorithmic thinking through visual output.

The project includes **10+ different patterns** ranging from basic half pyramids to complex structures like Floyd's Triangle and Pascal's Triangle.
