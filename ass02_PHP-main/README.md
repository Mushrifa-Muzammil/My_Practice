## 📖 About The Project

This is an **enhanced Grocery Bill Calculator** that demonstrates intermediate PHP concepts:

- Collecting user input via HTML forms
- Processing form data with PHP arrays and loops
- Dynamic bill breakdown with itemized display
- Responsive, modern UI with gradient design

Unlike a basic calculator, this version shows a **detailed bill breakdown table** with individual item costs, quantities, and a grand total – just like a real grocery receipt!

## ✨ Features

| Category | Features |
|----------|----------|
| **Input Form** | 6 grocery items with quantity fields (supports decimals for Dhal) |
| **Bill Breakdown** | Detailed table showing each item, quantity, unit price, and subtotal |
| **Smart Filtering** | Only items with quantity > 0 appear in the bill |
| **UI/UX** | Modern gradient design, hover effects, responsive layout |
| **Data Types** | Supports integers (items) and decimals (Dhal per kg) |
| **Validation** | Required fields, numeric input validation |
| **Navigation** | Easy back-link to calculator from results page |

## 🛠️ Built With

- **HTML5** – Semantic form structure
- **CSS3** – Modern gradient styling, flexbox, hover effects, responsive design
- **PHP 7+** – Dynamic calculation, array processing, bill generation
