## 📖 About The Project

This is a **modern, fully responsive moving company website** designed for "Move It" – a startup moving service based in the US. The website showcases the company's services, values, and professional approach to making moving stress-free and enjoyable.

The template features:
- **Hero section** with compelling headline and call-to-action buttons
- **Feature highlights** (Professional, Countrywide, Personal Touch)
- **Image carousel** showcasing customer experiences
- **Postcode checker** for service availability
- **Responsive navbar** with dropdown menu
- **Professional footer** with navigation links

## ✨ Features

| Category | Features |
|----------|----------|
| **Navigation** | Responsive navbar with brand logo, dropdown menu, search/postcode input |
| **Hero Section** | Catchy headline, descriptive text, dual CTA buttons (Get a Quote, Contact Us) |
| **Features** | 3 value propositions with icons (Professional, Countrywide, Personal Touch) |
| **Carousel** | Bootstrap image slider with customer/lifestyle photos |
| **Footer** | Multi-column layout with navigation links and copyright |
| **Design** | Bootstrap 5 components, custom feature icons, gradient styling |
| **Responsive** | Fully responsive across desktop, tablet, and mobile |

## 📄 Sections Overview

| Section | Description |
|---------|-------------|
| **Navbar** | Brand logo ("Move It"), Home/About/Services links, postcode search form |

| **Footer** | Copyright notice and navigation links |

## 🛠️ Built With
