## 📖 About The Project

This is a **modern, fully responsive agency website template** designed for digital agencies, marketing firms, and creative businesses. The template features a professional gradient-based design with smooth scrolling navigation and Bootstrap's responsive grid system.

The template includes all essential sections for a business website:
- **Hero banner** with call-to-action
- **Services showcase** with icons and descriptions
- **About/Why choose us** section with feature list
- **Testimonials** section with client reviews
- **Social media links** with hover effects
- **Contact/Footer** with newsletter signup

## ✨ Features

| Category | Features |
|----------|----------|
| **Navigation** | Sticky navbar, smooth scrolling, responsive mobile menu |
| **Hero Section** | Gradient background, call-to-action with video link, animated waves |
| **Services** | 3 service cards with images, titles, and descriptions |
| **About Section** | Feature list with checkmarks, illustrative image |
| **Testimonials** | Client quotes with avatars and positions |
| **Social Media** | Icon row with hover lift effects |
| **Footer** | Contact info, newsletter signup, copyright |
| **Design** | Purple gradient theme (→ #a517ba to #5f1782), smooth transitions |

## 📄 Sections Overview

| Section | ID | Description |
|---------|-----|-------------|
| **Navigation** | `#nav-bar` | Fixed-top navbar with logo and menu links |
| **Banner** | `#banner` | Hero section with title, description, and CTA button |
| **Services** | `#services` | Three service offerings (Growth Marketing, Online Branding, Animated Ads) |
| **About Us** | `#about-us` | Why choose us section with feature list |
| **Testimonials** | `#testimonials` | Client reviews with avatars |
| **Social Media** | `#social-media` | Social media icon links |
| **Footer** | `#footer` | Contact details, newsletter subscription, copyright |
