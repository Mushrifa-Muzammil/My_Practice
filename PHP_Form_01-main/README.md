## 📖 About The Project

This project demonstrates a **complete client-server form handling system** with robust validation on **both sides**:

- **Client-side (JavaScript):** Provides immediate user feedback before submission.
- **Server-side (PHP):** Performs thorough validation, sanitizes input, and securely displays submitted data.

It's an excellent learning example for understanding form validation, data sanitization, and the request-response cycle in web development.

## ✨ Features

| Category | Features |
|----------|----------|
| **Form Fields** | Name, Email, Website, Comment, Gender (radio buttons) |
| **Client-side Validation** | JavaScript checks for empty Name and Email fields |
| **Server-side Validation** | Required fields, email format, URL format, gender selection |
| **Security** | Input sanitization with `trim()`, `stripslashes()`, `htmlspecialchars()` |
| **User Experience** | Sticky form values, inline error messages, success display |
| **Design** | Gradient background, card-style container, responsive layout |

## 🛠️ Built With

- **HTML5** – Semantic form structure
- **CSS3** – Modern gradient styling, responsive design
- **JavaScript (ES6)** – Client-side validation
- **PHP 7+** – Server-side validation and data processing
